학습 정보

한자친구는 별도의 개발자 회원가입을 요구하지 않습니다. 한자별 읽기·쓰기 출제 이력, 채점 결과, 학습 날짜, 복습 정보는 기기의 앱 저장소에 보관합니다. 손으로 쓴 필기 이미지는 저장하거나 광고 서비스에 전달하지 않습니다. 급수 선택과 미완료 필기는 기기별로 유지합니다.

iPhone·iPad·iPhone Duo에서는 같은 iCloud 계정의 기기 사이에서 학습 기록을 이어가기 위해 Apple의 CloudKit 개인 데이터베이스를 사용합니다. 개발자는 사용자의 iCloud 로그인 비밀번호를 받지 않습니다. iCloud 기능은 계정·네트워크·시스템 설정과 서비스 활성화 상태에 따라 달라집니다. 앱을 삭제해도 이미 iCloud에 저장된 정보가 함께 삭제된다고 보장하지 않습니다. iCloud 저장 정보는 기기의 iCloud 저장 공간 관리 기능을 확인하거나 아래 연락처로 문의하세요.

Android의 선택적 계정과 동기화

Android에서는 로그인 없이 기기 내 학습을 이용할 수 있습니다. 사용자가 Google 로그인을 선택하면 Firebase Authentication이 계정 식별자와 이메일 등 로그인 정보를 처리하고, Firebase Cloud Firestore에 해당 계정의 학습 기록을 동기화합니다. 로그인 전 게스트 기록은 첫 로그인한 계정으로 이전합니다. iCloud와 Firebase 사이의 교차 플랫폼 동기화는 제공하지 않습니다. Google 계정 비밀번호를 개발자가 받지 않습니다.

Firestore 학습 데이터 저장 리전은 서울(asia-northeast3)이며, Google 로그인·인증 및 서비스 운영 정보는 Google의 서비스 처리 정책을 따릅니다. 필기 이미지와 획 좌표는 Firebase에 보내지 않습니다. Google Analytics는 사용하지 않습니다. 로그아웃하면 계정별 학습 기록을 분리해 표시하며 기존 계정의 로컬 기록을 다른 계정에 옮기지 않습니다. 앱을 삭제하면 기기 내 기록이 삭제되지만 이미 동기화된 기록은 계정에 남을 수 있습니다.

앱의 ‘학습 기록 동기화’에서 ‘계정과 동기화 기록 삭제’를 선택할 수 있습니다. 최근 로그인 확인 후 Firebase 계정과 학습 기록을 삭제하며 Google 계정 자체는 삭제하지 않습니다. 다른 기기의 지연 업로드가 기록을 다시 만드는 일을 방지하기 위해 최소 삭제 표시(기존 Firebase UID와 삭제 여부)는 보관합니다. 삭제 작업이 연결 오류 등으로 중단되면 다시 로그인해 재시도하거나 아래 주소로 문의하세요. 상세한 제3자 정보 처리는 Firebase의 개인정보 및 보안을 참고하세요.

오류 진단

Android 1.0(2), iOS 1.0(6)부터 Firebase Crashlytics로 앱 비정상 종료·오류 스택, 앱·운영체제 버전, 기기 모델과 진단용 설치 식별자를 수집하여 안정성을 개선합니다. 학습 답안·필기·이메일·Firebase 사용자 UID를 진단 로그나 사용자 식별자로 추가하지 않습니다. Google Analytics는 추가하지 않습니다. 개발용 Debug 빌드는 오류 수집을 비활성화합니다. 오류 진단은 광고 추적과 별개이며 광고 개인화에 사용하지 않습니다. 정보 처리와 보관은 Firebase 개인정보 안내를 따릅니다.

광고와 개인정보 선택

iOS 1.0(5)부터 광고 관련 SDK나 동의창을 시작하기 전에 Apple의 앱 추적 투명성(ATT) 권한을 요청합니다. 권한 결과가 결정되면 Google의 지역별 광고 동의 절차를 진행합니다. 거절·제한 상태에서도 광고를 표시할 수 있지만 Google SDK는 IDFA를 광고 요청에 보내지 않습니다. 광고 요청 여부와 제공 가능한 광고 유형은 별도의 지역별 동의 상태에 따릅니다. 모든 학습 기능은 권한 선택과 관계없이 사용할 수 있습니다. 설정에서 권한을 변경한 뒤 앱을 다시 실행하면 새 선택을 반영합니다. ATT 허용과 광고 동의는 별개이며, 허용해도 앱은 비개인화 광고 설정을 유지합니다. 현재 Android 1.0(3) 출시 빌드에서는 광고가 비활성화되어 있습니다.

한자 목록 화면은 Google AdMob 배너 광고를 표시할 수 있습니다. 암기·필기·채점 화면에는 광고를 표시하지 않습니다. 앱은 개인 맞춤 광고를 요청하지 않도록 설정하고, 최대 광고 콘텐츠 등급을 일반 대상(G)으로 제한합니다. 전면 광고나 보상형 영상은 사용하지 않습니다. 이러한 설정이 모든 광고 소재의 적합성이나 제3자 데이터 처리가 없음을 보장하는 것은 아닙니다.

Google Mobile Ads SDK와 User Messaging Platform은 광고 제공, 부정 사용 방지, 진단 및 동의 선택 처리를 위해 네트워크 정보(IP 주소 등), 기기·앱 정보, 광고 노출·상호작용, 진단 정보와 개인정보 선택 상태 등을 처리할 수 있습니다. 비개인화 광고도 이러한 처리를 수반할 수 있습니다. 앱의 학습 정오답과 필기 내용은 광고 요청에 넣지 않습니다. ATT를 거절해도 비추적 광고 제공에 필요한 정보 처리는 발생할 수 있습니다.

필요한 지역에서는 Google의 개인정보 메시지를 표시합니다. 광고는 SDK가 요청 가능한 상태라고 확인한 뒤 요청하며, 동의 확인이나 광고 로드가 실패해도 학습 기능을 사용할 수 있습니다. SDK가 개인정보 선택 변경 기능을 요구하는 경우 목록 화면의 ‘광고 개인정보 설정’에서 선택을 다시 확인할 수 있습니다.

Google이 처리하는 정보와 보관 기간, 권리 행사 절차는 Google 개인정보처리방침, Google이 파트너 앱의 정보를 사용하는 방법을 확인하세요. SDK 데이터 항목의 기술적 설명은 Google iOS 데이터 공개 안내와 Google Android 데이터 공개 안내에 있습니다. 제3자 처리 기간을 개발자가 임의의 고정 기간으로 보장하지 않습니다.
