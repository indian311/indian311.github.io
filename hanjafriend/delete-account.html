계정과 학습 기록 삭제

말랑소프트의 한자친구 Android 앱에서 Google 로그인으로 만든 앱 계정과 동기화 학습 기록을 삭제하는 방법입니다. 최종 갱신: 2026-11-05.

앱 없이 삭제 요청하기

앱을 다시 설치할 필요 없이 indian311@icloud.com으로 계정 삭제를 요청하세요 ↗.

  1. 한자친구에 로그인했던 Google 계정의 이메일 주소에서 요청 메일을 보내세요. 다른 주소에서 보내는 경우 계정 확인을 위해 추가 안내를 드릴 수 있습니다.
  2. 제목에 ‘한자친구 Android 계정 삭제 요청’, 본문에 ‘한자친구 앱 계정과 연결된 동기화 학습 기록의 삭제를 요청합니다’라고 적어 주세요.
  3. 계정 소유자 확인 후 삭제를 진행하고 처리 결과를 답장으로 안내합니다. 비밀번호, 인증번호, 결제정보는 보내지 마세요. 보호자가 대신 문의하는 경우에도 삭제 전 계정 소유 확인이 필요합니다.

앱에서 직접 삭제하기

한자 목록 상단의 동기화 설정 → ‘학습 기록 동기화’ → ‘계정과 동기화 기록 삭제’를 선택하세요. 최근 로그인 확인 후 삭제합니다. 연결 오류 등으로 중단되면 다시 로그인해 재시도하거나 위 이메일로 요청하세요.

삭제되는 정보

한자친구의 Firebase Authentication 계정 및 그 계정에 연결된 Cloud Firestore 학습 기록(한자별 읽기·쓰기 출제와 채점 결과, 학습 날짜 및 복습 정보)을 삭제합니다. 앱에서 직접 삭제하면 해당 기기의 계정별 학습 기록도 삭제합니다. Google 계정 자체와 다른 앱의 데이터는 삭제하지 않습니다. 이 작업은 복구할 수 없습니다.

보관되는 정보와 주의사항

  • 다른 기기의 지연 업로드로 삭제된 기록이 다시 생성되는 것을 막기 위해 기존 Firebase UID와 삭제 여부만 있는 최소 삭제 표시를 보관합니다. 학습 기록이나 이메일은 이 표시에 보관하지 않으며, 고정된 자동 만료 기간은 설정하지 않았습니다.
  • 이메일 요청만으로 다른 기기의 오프라인 저장소를 원격으로 지우지는 않습니다. 다른 기기의 계정별 로컬 기록과 로그인 전 게스트 기록을 지우려면 해당 기기의 앱 데이터를 지우거나 앱을 삭제하세요.
  • 계정을 식별하는 이메일이나 UID를 Crashlytics에 추가하지 않으므로 기존 익명 진단 자료를 특정 계정에 연결해 삭제하지 못할 수 있습니다. 진단 자료와 서비스 백업의 보관·삭제는 Firebase 개인정보 안내를 따릅니다.
  • 삭제 요청과 소유자 확인에 사용된 문의 메일은 요청 처리와 처리 결과 확인에 사용합니다. 별도 고정 자동 삭제 기간을 설정하지 않았으며, 문의 메일 삭제도 같은 주소로 요청할 수 있습니다.

이 안내는 Android 앱 계정에 적용됩니다. iPhone·iPad의 iCloud 학습 정보는 별도 저장소이며 개인정보처리방침의 iCloud 안내를 확인하세요.
