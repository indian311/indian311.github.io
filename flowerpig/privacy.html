게임 이용과 기기 저장

별도의 개발자 회원가입 없이 기본 게임을 플레이할 수 있습니다. 최고 점수·최고 높이·플레이 횟수, 음악·효과음·진동 설정과 안내 확인 여부를 기기에 저장합니다. 온라인 순위 전송을 기다리는 기록이 있으면 해당 플랫폼 플레이어 식별자와 점수도 기기에 저장합니다. 이 기록을 받는 별도의 말랑소프트 게임 서버는 없습니다.

기기 기록은 앱 데이터가 유지되는 동안 저장됩니다. 앱 데이터 삭제나 앱 제거로 기록이 사라질 수 있으며 운영체제의 백업·복원 설정에 따라 복원될 수 있습니다.

선택적인 온라인 게임 서비스

온라인 서비스가 설정된 배포본에서는 사용자가 연결한 Apple Game Center(iOS) 또는 Google Play Games(Android)의 플레이어 식별자를 확인하고 점수를 전송하며 순위표를 표시합니다. 로그인한 상태에서 게임이 끝나면 해당 계정에 점수 전송을 시도합니다. 1.0 버전에서는 사용자가 최고 기록 전송을 선택할 수도 있습니다. 게임은 Apple·Google 계정 비밀번호를 직접 수집하지 않습니다. 온라인 연결 없이도 기본 게임과 기기 기록은 이용할 수 있습니다.

1.1.0(8) 이상 테스트 배포본에서는 iOS 앱의 첫 화면에서 Game Center 인증을 자동으로 요청합니다. Android는 기기에 저장된 만 14세 도달 시각이 지난 경우에만 앱 시작 시 Play Games 연결을 자동으로 시도합니다. Android에서 연령을 확인하지 않았거나 만 14세 미만이면 앱 시작 시 SDK나 연령 입력 화면을 실행하지 않습니다. 연령 미확인 이용자는 기록장의 로그인 기능을 선택해 빈 생년월일 입력 화면에서 연령을 확인할 수 있습니다. 인증이 취소되거나 실패해도 기본 게임을 게스트로 이용할 수 있습니다. 연결된 계정으로 플레이한 점수는 게임 종료 시 자동으로 전송을 시도합니다. 전송에 실패한 점수는 계정별로 기기에 보관하고 해당 계정에 다시 로그인하거나 앱을 다시 실행하거나 앱으로 돌아왔을 때 자동으로 재시도합니다. 이 테스트 배포본에서는 수동 최고 점수 전송 버튼을 제공하지 않습니다. 게스트로 플레이한 기록은 기기에 유지하며, 나중에 로그인한 계정이나 다른 계정에 자동으로 귀속하거나 전송하지 않습니다. 이 변경은 1.0.0(7) 정식 배포본의 동작을 소급하여 변경하지 않습니다.

플랫폼 사업자는 계정·게임 활동과 서비스 정보를 각자의 정책에 따라 처리하며, 순위표의 프로필·점수 공개 범위는 플랫폼 정책과 설정에 따릅니다. Android에서 온라인 연결 기능을 사용하면 Google Play Games SDK가 서비스 안정성·개선을 위한 진단·분석 정보를 자동 처리합니다. 점수는 연결된 게임 계정에 전송되며, Google Play Games 서비스의 데이터 전송은 HTTPS로 암호화됩니다. 앱에는 별도의 광고 SDK나 사용자 행동 분석 SDK가 없습니다. 플랫폼 SDK의 정보 처리까지 전혀 없다는 뜻은 아닙니다.

Android 온라인 연결과 연령 확인

Android 1.0.0(7) 이상에서는 온라인 계정 연결을 처음 선택할 때 생년월일을 입력하는 연령 확인 화면을 표시합니다. 입력값은 기기에서만 처리하며 외부로 전송하지 않습니다. 원본 생년월일 입력값 대신 만 14세가 되는 시각만 앱 전용 기기 저장소에 보관합니다. 한국 배포본에서는 만 14세 미만이거나 연령을 확인하지 않은 경우 Google Play Games SDK를 초기화하거나 로그인·점수 전송·순위표 기능을 실행하지 않습니다. 저장된 시점에 도달하면 온라인 연결을 선택할 수 있습니다. 연령 확인을 취소하거나 온라인 연결을 이용하지 않아도 기본 게임과 기기 기록을 이용할 수 있습니다. 앱 데이터 삭제 시 이 연령 확인 정보도 삭제될 수 있습니다.

기록 공유

기록 공유를 선택하면 점수가 포함된 문구를 운영체제의 공유 화면에 전달합니다. 실제 수신자와 공유 앱은 사용자가 선택합니다. 공유를 취소하면 게임이 다른 사람에게 문구를 직접 전송하지 않습니다. 이후 정보 처리는 사용자가 선택한 앱의 정책을 따릅니다.

권한과 추적

게임은 카메라·마이크·연락처·위치 권한을 요청하지 않습니다. Android 인터넷 권한은 온라인 게임 서비스에, 진동 권한은 선택적인 피격 진동에 사용합니다. 현재 구현에는 광고·게임 내 결제·광고 식별자를 이용한 추적·맞춤 광고가 없습니다.

보관과 삭제

앱 데이터 삭제·앱 제거는 기기 기록에 영향을 줍니다. 플랫폼 서버에 전송한 순위 기록은 Apple 또는 Google이 관리하므로 앱을 제거해도 함께 삭제된다고 보장하지 않습니다. 플랫폼의 게임 데이터·프로필 관리 기능 또는 해당 플랫폼 지원을 통해 관리·삭제를 요청할 수 있습니다. 말랑소프트가 별도로 운영하는 게임 가입 계정은 없습니다.

TestFlight 테스트

TestFlight 베타를 이용하면 Apple은 설치·이용 정보와 오류 진단을 자동으로 수집하고 앱 제공자와 공유합니다. 여기에는 초대 이메일, 앱·OS 버전, 기기 모델과 이용 정보가 포함될 수 있습니다. 직접 보내는 피드백에는 의견과 스크린샷이 포함될 수 있습니다. 말랑소프트는 베타 정보를 문제 조사와 앱 개선에 사용하며 열람·삭제 요청은 아래 문의 주소에서 받습니다. 이는 게임에 별도의 사용자 행동 분석 SDK를 추가했다는 뜻은 아닙니다. Apple TestFlight 개인정보 안내를 확인하세요.
